# Peoples Bakers — Full-Stack Bakery E-Commerce

Sri Lankan bakery e-commerce: browse products, check out in three steps (cart → details → complete), pay with **Cash on delivery** or **PayHere**, and manage orders from an admin dashboard.

**Author:** [Channa Sandeepa](https://github.com/sandeepa-cpu)

Application source lives in [`Peoples-Bakers-master/`](Peoples-Bakers-master/). That folder’s [README](Peoples-Bakers-master/README.md) has architecture, file pointers, env vars, and run commands.

**Stack:** HTML / CSS / vanilla JavaScript + Node.js / Express + SQLite (not Next.js). GitHub Pages will not run this app.

```bash
cd Peoples-Bakers-master
npm install
copy .env.example .env
npm start
```

Then open http://localhost:3000
